El colab "Enith_Perez_ Hands - On: Herramientas de Análisis de Datos.ipynb" hace una introducción a las librerías pandas y seaborn, trabajando con Segmentación de Datos y visualización.

El colab "Enith_Azul_Hands - On: Limpieza de Datos.ipynb" se aplica el tema  de  recompilación y limpieza de datos, en especial el saneamiento de columnas de valores de texto, numéricas y fechas.

El colab "Enith Azul_Hands - On: Exploración de Datos.ipynb" aplica el método del Rango Intercuartílico (IQR) para identificar y filtrar outliers, se identifican relaciones entre variables y se comunican de Hallazgos a través de Narrativa Visual.
